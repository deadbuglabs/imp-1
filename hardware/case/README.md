# IMP-1 enclosure — case files

Parametric case (build123d) modelled on the salvaged Uniden Stealth LRD 767 shell: top shell v2 (display window re-cut 19.5 x 34.5 mm portrait for the 22 x 38.5 mm Waveshare 1.47in module, with ledge pocket) and bottom panel. Watertight STL + STEP.

Shared publicly under the Deadbug Labs file-sharing split: case files, schematics and firmware are public; board manufacturing files (Gerbers/BOM/CPL) publish when the ordered revision is ordered. One local connector-relief notch may be added after the first dry-fit against real boards. The 3D-printing sponsorship for this case is sponsored by PCBWay (application via the PCBWay Community Hub).
